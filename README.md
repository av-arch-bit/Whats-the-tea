# What’s the Tea? 
A Slack bot which shares news for people who like to staying updated.

## You can try it here
https://app.slack.com/client/E09V59WQY1E/C0P5NE354

## Current Features
 You can use these Slash commands:
 - /whats-the-tea
 - /whats-the-tea-catfact - gives a cat fact
 - /whats-the-tea-joke - gives a joke

## Current Status
The bot doesn’t give news yet but it gives the basic structure to the news fetching idea.
